# Guard App Gates

Status: Candidate / No Runtime / No Customer Data

## Core Gates

- Check state before promising availability.
- Identify a specific unit before confirming a hold.
- Generated replies are drafts only.
- Do not double-hold the same unit and date.
- Maintenance access is not customer-data access.
- Display material must be official or authorized.

## Return Rule

Every mistake should return as a UI, schema, permission, template, or training improvement.
