**Repository class / 倉庫分類：** Public pole-oriented projection carrier  
**Operational status / 運作狀態：** Non-production  
**Authority model / 權限模型：** Repository ≠ Pole Authority; no implicit runtime, promotion, or world authority

## Overview / 概述

This repository is the GLModel-oriented GitHub projection of the CoreTri architecture. It is **not** the GLModel pole itself and does not replace lawful World / Object / Geometry / Engineering / Evidence authority.

本倉是 CoreTri 三極架構在 GitHub 生態中的 **GLModel 極向投影面**；它不是 GLModel 極本體，也不取代合法的 World／Object／Geometry／Engineering／Evidence Authority。

Its emphasis is World / Object / Geometry / Assembly / Engineering / Simulation / Evidence / Adapter / Projection / Lifecycle correspondence. DCP and Ideas representations may appear here only as bounded supporting projections needed to preserve dependency, meaning, authority, evidence and rebuild continuity.

本倉偏重 World／Object／Geometry／Assembly／Engineering／Simulation／Evidence／Adapter／Projection／Lifecycle Correspondence。DCP 與 Ideas 表徵只在維持 Dependency、Meaning、Authority、Evidence 與 Rebuild Continuity 所需時，以有界 supporting projection 出現。

## Tri-pole architecture / 三極架構

The three repositories do not assign one repository as one pole authority. All three reproduce the same CoreTri architecture in heterogeneous GitHub form; each repository gives different projection weight and working emphasis.

三倉不是「一倉＝一極 Authority」。三倉都在 GitHub 異質載體中重現同一 CoreTri 架構，只是投影重心與工作表面不同。

- **DCP-Pole-Projection** — dependency/state/authority/rebuild weighted.
- **Ideas-Pole-Projection** — meaning/placement/navigation/experience weighted.
- **GLModel-Pole-Projection** — world/object/engineering/evidence/adapter weighted.

Shared cross-repository material should remain bounded pointers, receipts, receiver states, returns, reconciliation and rebuild links. Shared material does not become a fourth pole, central truth body, or authority root.

跨倉 Shared Material 應維持 bounded pointer／receipt／receiver state／return／reconciliation／rebuild link；不得因此形成第四極、中央 Truth Body 或 Authority Root。
