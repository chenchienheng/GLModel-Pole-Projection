# Operator Flow

Status: Candidate / App Pattern / No Runtime

## Flow

1. Open daily screen.
2. Check state.
3. Choose action.
4. Generate draft if needed.
5. Human reviews.
6. Record result.
7. Return issue if something failed.

## Red Doors

- Draft is not sent message.
- Candidate action is not final action.
- App note is not live change.
