# App Roles

Status: Candidate / No Runtime

## Core

App support does not replace owner judgment.

## Roles

- Owner: decides rules and release gates.
- Operator: uses daily screens and reports issues.
- Maintainer: improves UI, rules, and notes from abstract returns.

## Red Doors

- Maintainer is not owner.
- Repair is not release.
- Pattern is not production.
- Candidate schema is not live database.
